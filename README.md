# RG Rotate Mahjong (3人麻雀 & 4人麻雀)

ANBERNIC RG Rotate (720x720 正方形画面) 向けに最適化された2D麻雀ゲーム（Godot 4.7 開発）。
内蔵ゲームパッドの物理ボタンのみで100%操作完結します。

---

## 🎮 特徴 & ゲームシステム
- **2つの対局モード**:
  - **4人麻雀 (四人打ち)**: 全136枚の牌を使用した本格東風/半荘戦。
  - **3人麻雀 (三人打ち・サンマ)**: 二萬〜八萬を除外したハイスピード打撃戦。
- **正方形画面 (720x720) 最適化**:
  - 自家の手牌、対面・上家・下家の河（捨て牌）、ドラ表示牌、点数表示をすべて720x720内に美しくレイアウト。
- **100% 物理ゲームパッド操作**:
  - 十字キー / スティック左右で手牌カーソル移動、Aボタンで打牌。
  - 上キー / Yボタンでアクションバー（ツモ・立直・パス）。
  - STARTボタンでポーズメニュー（入力貫通防止・確実なフォーカス復帰設計）。
- **プロシージャル効果音**:
  - 外部サウンドアセットに依存せず、打牌・ツモ・立直・決定音・フォーカス音を合成音声で軽快に再生。

---

## 🕹 コントローラー操作マッピング

| ボタン / 操作 | 機能 |
| :--- | :--- |
| **十字キー / 左スティック (左右)** | 手牌のカーソル移動 / UI選択 |
| **十字キー / 左スティック (上下)** | メニュー移動 / [上]でアクションバー呼出 |
| **A ボタン** | 打牌 (牌を捨てる) / 決定 (UI Accept) |
| **B ボタン** | キャンセル / アクションバー・設定を閉じる |
| **START ボタン** | ポーズメニュー表示 / ポーズ解除 |

## 🚀 ビルド & 実機自動デプロイ

### 前提条件
1. PCにANBERNIC RG RotateがUSBケーブルで接続されていること。
2. 実機側で「USBデバッグを許可」していること。

### デプロイコマンド (ワンクリック)

```powershell
# PowerShell の場合:
.\deploy.ps1
```

```bash
# Bash の場合:
./deploy.sh
```

上記スクリプトを実行すると以下が全自動で行われます:
1. `adb devices` で実機の接続・許可ステータスを確認。
2. Godot 4 のヘッドレスCLIで `build/rgrotatemahjong.apk` をエクスポート（デバッグ署名済み）。
3. `adb install -r` で実機へ転送・インストール。
4. `adb shell am start` で実機上でゲームを自動起動。
5. `adb logcat -s Godot` で起動ログを追跡監視。
